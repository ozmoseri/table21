# איך לפתוח בטלפון בדיוק את הגרסה שנבדקה

למה זה נחוץ: בסרטון מ-2.11 הטלפון הריץ גרסה ישנה, 7261b87 מבוקר 1.11. המחשב מגיש לטלפון את מה שיש בתיקייה `C:\Users\user\table21`, והתיקייה הזאת לא עודכנה מאז. החשבונות והקוינס שמורים בתיקייה `.data\lan` ונשארים גם אחרי עדכון.

## 1. לעדכן את התיקייה במחשב

פותחים PowerShell בתיקייה `C:\Users\user\table21` ומריצים:

```
git pull
```

העדכון מוריד בפעם הראשונה כמה מאות MB, בעיקר צילומי מסך של הבדיקות.

בדיקה: `git log -1 --oneline` צריך להראות את הקומיט שמופיע בהודעת הסיום של Claude, או קומיט חדש יותר.

אם `git pull` נעצר כי השתנו קבצים מקומיים, לא מוחקים כלום. שולחים ל-Claude את ההודעה.

## 2. לסגור את השרת הישן ולהפעיל מחדש

1. סוגרים את חלון ה-PowerShell שמריץ את השרת הקודם, החלון שנפתח מ-`START-LAN-WINDOWS.cmd`. אם לא בטוחים, מפעילים מחדש את המחשב.
2. לוחצים פעמיים על `START-LAN-WINDOWS.cmd`. הוא מתקין את מה שחסר, בונה את המשחק מחדש כי הקוד חדש יותר, ומציג כתובת ו-QR.

## 3. בטלפון

1. פותחים את הכתובת שהמחשב מציג, אותה רשת Wi-Fi. מצב רגיל: `http://10.0.0.26:3021`.
2. אם המשחק כבר היה פתוח בגרסה הישנה, תופיע הודעת "גרסה חדשה". לוחצים "רענון" בין ידיים. לא צריך למחוק נתוני דפדפן.
3. מסך מלא: באייפון, Safari, שיתוף, "הוספה למסך הבית", ואז פותחים מהאייקון. ב-Safari רגיל הסרגלים תמיד נראים.

## 4. לוודא שזו הגרסה הנכונה

הגדרות, ואז "אודות ואבחון" בסוף המסך:
- **גרסת המשחק:** אותו קומיט כמו בהודעת הסיום.
- **גרסת השרת:** אותו קומיט ואותו מזהה build.
- **שורה ירוקה:** "המשחק והשרת באותה גרסה."
- **מצב:** "מותקן ממסך הבית" כשפותחים מהאייקון.

צילום מסך של המסך הזה מהטלפון הוא ההוכחה לגרסה שנבדקה.
